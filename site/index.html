Run your own Minecraft network.

Vectolyn is an open-source kit under GPL-3.0. You host the network yourself, and Java players from 1.8 to 26.3 join the same servers as Bedrock players.

Stage 2 of 8. There is no usable cloud release yet, and parts of the architecture below are still a plan.

Source on GitHub Getting started

What runs where

Proxy
Velocity is the single entry point. Geyser and Floodgate let Bedrock clients in, and ViaVersion, ViaBackwards and ViaRewind translate older Java versions.
Servers
Paper runs Lobby, Survival, Creative, End and later the minigames. Fabric runs the mod server. Command blocks stay off on every server.
VectolynCloud
A Java node with a console and a setup wizard, under construction in stage 2. It will download and verify server software, manage Java runtimes and the database, generate secrets and scale minigame servers.
Vectolyn plugin
Planned for stage 3: one jar per platform for Paper, Velocity and Fabric, replacing LuckPerms, TAB, WorldEdit, WorldGuard, PlaceholderAPI, ProxyPortal and Chunky.
Database
MariaDB or MySQL.

We do not run a network ourselves. There is no official server to join, and no hosted Discord bot or store. The website, Discord bot and store are code in the repository that you host with your own bot token and your own Stripe account.
