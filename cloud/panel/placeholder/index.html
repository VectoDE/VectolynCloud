VectolynCloud Panel

The panel server runs, but this build of VectolynCloud does not contain the panel frontend.

Release builds contain it. To build it yourself, install Node.js 20.9 or newer and run ./gradlew build -Pvectolyn.panel.web=true. See docs/cloud/panel.md.

Der Panel-Server läuft, aber dieser Build enthält die Oberfläche nicht. Release-Builds enthalten sie.
