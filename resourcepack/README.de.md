# Resourcepack

[English](README.md) · **Deutsch**

Quellen des Vectora-Resourcepacks und das Werkzeug, das es für Java 1.8 bis zur neuesten Version und für Bedrock baut. Noch liegt hier nichts; das Pack kommt in Etappe 7.

Das Pack ist optional. Im Einrichtungsassistenten und im Dashboard wählst du das Vectora-Pack (Vorgabe), ein eigenes oder keins.
