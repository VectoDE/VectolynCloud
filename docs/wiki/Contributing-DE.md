# Mitmachen

[English](Contributing)

Die vollständigen Regeln stehen in [CONTRIBUTING.de.md](https://github.com/VectoDE/VectoraCloud/blob/main/CONTRIBUTING.de.md). Kurzfassung:

1. In die [Roadmap](https://github.com/users/VectoDE/projects/11) schauen und ein Issue aussuchen oder anlegen. Issues mit dem Label `good first issue` sind für den Einstieg gedacht.
2. Bei allem, was größer ist als ein kleiner Fix, erst auf eine Antwort im Issue warten.
3. Von `main` abzweigen, kleine Commits machen, [Conventional Commits](https://www.conventionalcommits.org/de/) schreiben und jeden Commit mit `git commit -s` abzeichnen.
4. `./gradlew build` ausführen, dann einen Pull Request mit `Fixes #123` öffnen.

Worauf es in diesem Projekt ankommt:

- Bedrock-Spieler müssen nutzen können, was du baust.
- Keine neuen Fremd-Plugins außerhalb der erlaubten Basis.
- Texte für Spieler und Admins auf Deutsch und Englisch.
- Keine Secrets, IPs, Spielerdaten, Welten oder Jars in Commits.

## Dieses Wiki bearbeiten

Das Wiki entsteht aus [`docs/wiki/`](https://github.com/VectoDE/VectoraCloud/tree/main/docs/wiki) im Repository. Bearbeite die Dateien dort per Pull Request. Englische Seiten haben kein Suffix, deutsche enden auf `-DE`. Nach einem Merge auf `main` kopiert ein Workflow sie ins Wiki; Änderungen direkt im Wiki werden überschrieben.

Fragen: [Discussions](https://github.com/VectoDE/VectoraCloud/discussions).
